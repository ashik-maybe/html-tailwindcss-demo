Build any UI with Tailwind CSS

Utilities compose in HTML instead of custom CSS. Every class below is a small, single-purpose rule Tailwind generated because this file uses it.

01

Hover-sensitive children

Parent has group, child has group-hover:. The icon inverts color when you point at the whole card.

02

Transitions, not magic

transition animates whatever property changes (translate, shadow, color) over ~150ms by default. duration-300 slows it to 300ms.

03

Dark mode pairs

Notice dark:bg-* and dark:text-* sitting next to every light value. Toggle the button above — the whole page flips because .dark lives on <html>.
