Forms & validation

A form is a form element containing labelled fields. The browser already knows how to validate most inputs — your job is to declare the rules and surface the errors clearly.

The pieces

<form>
  <label for="email">Email</label>
  <input id="email" name="email" type="email" required />

  <fieldset>
    <legend>Notifications</legend>
    <label><input type="radio" name="n" /> All</label>
    <label><input type="radio" name="n" /> None</label>
  </fieldset>

  <button type="submit">Save</button>
</form>
  • Every input needs a label. Tie them with for↔id so clicking the label focuses the field, and screen readers announce its name.
  • type changes behaviour: email, number, password, date, checkbox, radio.
  • Group related controls in a fieldset with a legend.

Free validation: use attributes

You often need no script to validate. These attributes make the browser block submission and show a native message:

AttributeRule
requiredmust not be empty
type="email"must look like an email
minlength="3"at least 3 characters
pattern="\d{4}"must match a regular expression
min / maxnumeric bounds

In JS, input.validity.valid is a boolean you can read, form.checkValidity() tests the whole form, and input.setCustomValidity("msg") adds your own rule.

Showing errors accessibly

Colour alone is not enough — colour-blind users and screen readers miss it. Three attributes do the real work:

  • aria-invalid="true" tells assistive tech the field is wrong.
  • aria-describedby="email-error" links the field to its message, so the message is read out when focused.
  • A visible message element with that id, plus a border-red-500 for sighted users.
email.setAttribute('aria-invalid', String(!valid))
errorEl.classList.toggle('hidden', valid)

Live example — a real validated form

Try submitting it empty, then with a bad email, then correctly. The script below is exactly what runs it.

Please enter a valid email address.

const form = document.querySelector('#demo-form')
const email = document.querySelector('#email')
const errorEl = document.querySelector('#email-error')

function validate() {
  const valid = email.validity.valid
  email.setAttribute('aria-invalid', String(!valid))
  errorEl.classList.toggle('hidden', valid)
  return valid
}

email.addEventListener('input', validate)

form.addEventListener('submit', (event) => {
  event.preventDefault()          // stop the page from reloading
  if (!validate()) return         // block submit while invalid
  document.querySelector('#demo-out').textContent = 'Saved: ' + email.value
})

Two real examples in the app: the Authentication view (error alert with focus management) and Checkout (a pay button disabled until every step is valid).

Exercise

  1. Add a "Full name" field with required minlength="2" and its own error message.
  2. Add a checkbox for "I agree" that must be checked — required on a checkbox means "must be checked".
  3. Keep the Save button disabled (disabled opacity-50) until the whole form is valid, using form.checkValidity() on every input event.
