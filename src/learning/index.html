Learn HTML → Tailwind → modern UI

Ten standalone lessons that assume you have never written a web page before. Each one is a complete document you can View Source on. Read them in order, do the exercise at the end of each, then open the pattern library and read real pages built the same way.

How to use these lessons

Read a lesson → close the file → rebuild one example from memory → diff your version against the original. Typing it out is what makes it stick; reading alone won't.

Stage 1 · Beginner

Move on when you can read any page in the app and explain each class, and copy + tweak a card or form without breaking it.

  • 01 HTML basics Tags, attributes, nesting, and the full document skeleton.
  • 02 Tailwind basics The class attribute, utilities, and the spacing/color scales.
  • 03 Layout basics Box model, flex, grid, responsive, states, and dark mode.

Stage 2 · Intermediate

Move on when you can build an interactive page — a form with validation, plus loading and error states — from a mockup, without copying.

  • 04 Forms & validation Labels, native validation, error states, and submit gating.
  • 05 Animations & transitions Transitions, transforms, keyframes, and honoring reduced motion.
  • 06 JavaScript & the DOM Selecting elements, events, delegation, and how the app swaps views.
  • 07 Design tokens & CSS Custom properties, @theme, arbitrary values, and when to write CSS.

Stage 3 · Advanced

Move on when you can scaffold a framework app, route between screens, manage state, and ship UI that is accessible and fast.

  • 08 Data & async async/await, loading/success/empty/error, retry, and race guards.
  • 09 Accessibility Semantics, keyboard, focus, ARIA, and how to test it.
  • 10 Architecture & frameworks SPA patterns, components, where React/Vue fit, and what's next.

One honest caveat

These lessons teach the pattern track. Reaching "build any modern UI" also needs hands-on CSS depth, real JavaScript practice, and a framework — so the roadmap in GETTING-STARTED.md (in the repo) names those tracks and where to go for each.
