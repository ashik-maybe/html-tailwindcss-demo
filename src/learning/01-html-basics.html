HTML basics

HTML is how you put content on a web page: text, images, buttons, links. It is not a programming language — there is no logic, no maths, no loops. You write content and wrap parts of it in tags to say what each part is. That is the whole idea.

A tag, an element, an attribute

These three words confuse beginners, so pin them down now:

<p class="intro">Hello</p>
  • Tag — the name in angle brackets: <p> opens, </p> closes. p means "paragraph".
  • Element — the opening tag + its content + the closing tag, together.
  • Attribute — extra information inside the opening tag, written as name="value". Here class="intro" labels the paragraph (lesson 2 uses this heavily).

A few elements have no closing tag and no content — they stand alone: <img>, <input>, <br>. The trailing slash (<img />) is optional.

Nesting and indentation

Elements can contain other elements. They must close in the order they opened, like nested brackets. Indent children by two spaces so the structure is visible at a glance. 

<ul>
  <li>Coffee</li>
  <li>Tea</li>
</ul>

ul is an unordered (bulleted) list; each li is a list item. The indentation changes nothing for the browser — it is purely so you can read it.

Block vs inline

Block elements start on a new line and stretch full width: div, p, h1, ul. Inline elements flow inside a line of text: span, a, strong, em.

The elements you will use most

ElementWhat it means
<h1>…<h6>Headings, biggest to smallest. One h1 per page.
<p>A paragraph of text.
<a href="…">A link. href is the destination.
<button>Something you click that does an action (not a link).
<img src="…" alt="…">An image; alt describes it for screen readers.
<ul> / <ol> / <li>Bulleted / numbered lists and their items.
<div>A generic block box, used to group things.
<span>A generic inline box, used to style a word or two.

There are also semantic elements that say what a region is: header, nav, main, section, footer. They behave like a div visually, but tell assistive tech (and you) what the box is. Lesson 09 covers why that matters.

The full document skeleton

Every web page has the same frame. Here is the smallest useful one: 

<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>My first page</title>
  </head>
  <body>
    <h1>Hello</h1>
    <p>My first paragraph.</p>
  </body>
</html>
  • <!doctype html> — "this is modern HTML", always line one.
  • <html lang="en"> — the root element; lang tells screen readers which language to pronounce.
  • <head> — information about the page. Nothing here is visible in the page body.
  • <title> — the name in the browser tab.
  • charset and viewport — encoding and "scale correctly on phones". Copy them into every page.
  • <body> — everything you actually see.
You are looking at exactly this skeleton right now. In your browser, choose View → Developer → View Source: everything above the visible lesson is the <head>.
