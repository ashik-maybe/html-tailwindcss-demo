Layout basics

So far you have styled individual elements. Layout is about how they sit relative to each other. Get comfortable with the four ideas here and you can build almost any screen.

The box model

Every element is a rectangle made of four layers, from inside out: content → padding (space inside the border) → border → margin (space outside, pushing neighbours away). The classes map directly: p-4, border, m-4.

Live example — margin pushes the outer box in

content

Dashed = margin · brand border = border · inner tint = padding + content.

  • p-4 padding on all sides; px-4/py-2 one axis; mt-4 one side.
  • m- for margin, same number scale. mx-auto centres a block that has a width.
  • space-y-4 adds even vertical gaps between children — handy in lists and forms.

Flexbox — a row (or column) that shares space

Put flex on a container and its children line up in a row. Then you steer them: items-center centres them vertically, justify-between pushes the ends apart, gap-3 spaces them, and flex-1 makes a child grow to fill.

Grid — rows AND columns

When you want a set of cards in columns, reach for grid: grid gap-4 sm:grid-cols-3 means "one column by default, three columns from 640px up, with even gaps". Resize to watch it reflow.

Responsive: mobile-first

Write the phone layout first, then layer on wider screens with prefixes. sm: means "640px and wider", md: 768px, lg: 1024px. There is no mobile: prefix — the base styles are mobile.

States — the same element, in different moments

Hover, focus and dark-mode are just more prefixes. A good rule from the app: focus states deserve the same care as hover, because keyboard users rely on them. That is why every interactive element here keeps a focus-visible:ring. 

<button class="bg-brand-600 text-white
               hover:bg-brand-700
               focus-visible:ring-2 focus-visible:ring-brand-500 focus-visible:ring-offset-2 focus-visible:outline-none
               active:scale-[0.98]">
  Press me
</button>
