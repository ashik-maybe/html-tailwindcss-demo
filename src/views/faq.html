FAQ

Answers to the questions this demo gets most.

Is this a real app or a demo?

Demo. Every button that would touch a server (pay, login, delete, subscribe) is deliberately inert or shows canned feedback. Clone it, read the comments, break it, ship your own version.

Why Tailwind v4 specifically?

v4 drops the config file for CSS-first setup: theme tokens live in @theme, variants like dark are declared with @custom-variant, and the Vite plugin compiles it all — no PostCSS config.

Do I need React to build something like this?

No. This whole site is ~700 lines of vanilla JS doing view swaps, delegation and a couple of listeners. Learn the platform first — then React's job (syncing state to DOM) becomes obvious instead of magic.

How does the sidebar remember nothing between reloads?

It always boots to the landing view — no router, no URL state. Only dark mode persists (localStorage). Adding hash routing (#/table) is the natural next exercise.

Why comment SO much?

The markup IS the lesson. Every comment answers "why these classes, not just what they do" — the reasoning you'd normally lose in a YouTube timestamp. Strip them freely once the patterns are yours.

Can I use this commercially?

Yes — copy, modify, ship. No attribution required (MIT on the repo). The patterns are the valuable part, and patterns don't belong to anyone.
