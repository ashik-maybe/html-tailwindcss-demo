Tooltip, popover, keyboard menu and combobox — keyboard-first, positioned without a library.

Tooltip — a label for the unlabelled

Opens on hover and on focus, closes on leave/blur/Escape. A tooltip you can only see with a mouse is a bug, not a feature. Never put a button or link inside one — it vanishes the moment you move the pointer toward it.

Popover — a disclosure you can click in

Unlike a tooltip, a popover holds interactive content, so it opens on click, takes focus, and closes on second click, Escape, outside-click or tabbing away. Same positioning engine — only the lifecycle changes.

Menu — arrows, Home/End, typeahead

The dashboard profile dropdown is the naive version: it opens but its items are only reachable by Tab. A role="menu" promises arrow-key navigation, so this one delivers the full contract — roving tabindex, ↑/↓ with wrap, Home/End, first-letter typeahead, Enter to activate, Escape to dismiss and return focus.
