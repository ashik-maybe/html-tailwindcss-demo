Features

Everything you need to launch

Batteries included: layouts, components and patterns — no design degree required.

01

Responsive grids

Mobile-first breakpoints: sm:, md:, lg: — layouts that grow with the screen.

02

Dark mode built-in

Class-based dark: variant from a single @custom-variant — toggle lives in the sidebar.

03

State utilities

Hover, focus, disabled, checked — expressed as classes (hover: focus-visible: disabled:), no JS state machines.

04

Design tokens

@theme in style.css turns CSS variables into utilities: brand color scales, fonts, radii.

05

Only what you use

The build scans your files and ships CSS for used classes only — Phase 0 shipped 20 kB total, framework and all.

06

Commented source

Every block explains WHY the classes are there — this whole app is built to be read, not just run.
