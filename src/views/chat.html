What's the difference between peer-checked and has-[:checked]?
peer-checked: styles a LATER sibling of a form input — one-way, linear. has-[:checked] styles an ANCESTOR based on what it contains — works when the input isn't a direct sibling. Checkout uses both: the radio dot uses peer-checked, the label box uses has-[:checked].
Nice. And why does hiding rows break even:?
Because even: compiles to :nth-child(even) — it counts DOM children, including hidden ones. The table re-stripes in JS instead, so filtered views stay correct.
